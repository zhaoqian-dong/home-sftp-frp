## 三、购买后必做的 3 件事

### 1. 记录公网 IP

进入 [轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse)，
在实例列表复制 **公网 IP**（如 `123.45.67.89`），填到项目 `.env` 的 `VPS_IP=` 后面。

### 2. 重置密码（或绑定 SSH 密钥）

控制台实例详情 → **重置密码**，设置 root 密码；
更安全的做法：实例详情 → SSH 密钥 → 创建/绑定密钥。

### 3. ⚠️ 控制台防火墙放行端口（最容易漏的一步）

轻量服务器自带**云端防火墙**（和系统内的 ufw 是两道独立关卡，本项目的脚本只能配置后者）：

实例详情 → **防火墙** 标签 → 添加规则，放行 TCP：

| 端口 | 用途 | 来源限制 |
|---|---|---|
| 22 | 你自己 SSH 管理 VPS | 建议限"我的 IP"或公司/常用出口 |
| 7000（FRP_BIND_PORT） | frp 隧道控制通道 | 全部（家里出口 IP 会变） |
| 6022（SFTP_PUBLIC_PORT） | 外网上传者连接 SFTP | 全部 |

漏放行是最常见的"连接超时"原因，详见 README 排障一节。

> 可选的 KCP 隧道（`.env` 里 `FRP_TRANSPORT=kcp`）基于 UDP：
> 启用后上表的 7000 还需**额外放行同端口的 UDP**（与 TCP 是两条独立规则），
> 漏放 UDP 的现象是 frpc 一直连不上。

## 四、连接 VPS 并部署

1. 控制台实例右侧点 **登录**（网页终端 OrcaTerm，免配 SSH 客户端），
   或在你自己的电脑上：`ssh root@<公网IP>`；
2. 把项目的 `scripts/setup-vps.sh`、`scripts/check-vps.sh` 和填好的 `.env` 上传到 VPS（在你本地电脑执行）：

   ```bash
   scp scripts/setup-vps.sh scripts/check-vps.sh .env root@<公网IP>:/root/
   ```

3. 在 VPS 上执行：

   ```bash
   cd /root
   bash setup-vps.sh
   ```

4. 部署自检：`bash check-vps.sh` —— 全部 PASS 即服务端就绪（WARN 按提示处理；
   全过但家里连不上时，优先查腾讯云控制台防火墙）。
   以后排查问题也可以随时重跑它；卸载则用 `scripts/uninstall-vps.sh`。

5. 按脚本结尾提示：**把生成的 FRP_TOKEN 回填到本地 .env**，
   再把 `.env` 和 `scripts/windows/` 目录复制到家里 Windows 机器（U 盘、局域网共享均可）。

## 五、带宽与流量须知

- 轻量应用服务器常见峰值带宽 **3~6 Mbps**（以购买页为准），折合下载约 0.4~0.8 MB/s；
- **所有外网↔家里的 SFTP 流量都经过这台 VPS 中转**，所以大文件传输速度上限 ≈ VPS 带宽；
- 轻量套餐一般按**流量包**计费（超出后按量付费或停机），传大文件前在控制台看一下剩余流量；
- 如果以后速度不够用：控制台可升级带宽/流量包，或换更高档套餐。

## 六、常见问题

**Q：需要备案吗？**
不需要。备案针对"域名 + 网站服务"；本项目只用 IP 和 TCP 端口。

**Q：999 买了之后还能改系统吗？**
可以。控制台 → 重装系统，选 Ubuntu 24.04，重装后重跑 `setup-vps.sh` 即可。

**Q：到期不续费会怎样？**
实例被回收，数据清空。VPS 上只有 frps 中转，家里才是数据本体，到期最多是"外网暂时传不了"，不影响已有数据。

**Q：端口被运营商/防火墙封了？**
国内 VPS 的 22/7000/6022 属正常端口；如怀疑被墙，可在 `.env` 改 `SFTP_PUBLIC_PORT` 为高位端口（如 16022），重跑脚本并在控制台防火墙同步放行。
